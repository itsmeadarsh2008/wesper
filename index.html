Import from JSPF

JSPF (JSON Shareable Playlist Format) is supported by ListenBrainz and other services. Import playlists with rich metadata including MusicBrainz identifiers.


Import from XSPF

XSPF (XML Shareable Playlist Format) is a standard XML playlist format supported by many media players including VLC, Audacious, and Clementine.


Import from XML

Import playlists from generic XML formats including iTunes XML playlists, Winamp XML, and other custom XML playlist formats.


Import from M3U/M3U8

M3U is the most widely supported playlist format. Import from any M3U or M3U8 playlist file. Track information is extracted from the extended M3U format.

          Lossless Audio on Mobile

          Wesper streams pure bit-perfect Lossless and Hi-Res audio directly to your device.

          Android users (Bluetooth LDAC/aptX)

          By default, Android downsamples high-resolution Bluetooth audio to save battery. To enable true 24-bit 96kHz playback:

          1. Enable Developer Options in Android Settings.
          2. Search for "Bluetooth Audio Codec" and select LDAC.
          3. Set "Bluetooth Audio Sample Rate" to 96.0 kHz.
          4. Set "Bluetooth Audio Bits Per Sample" to 24 bits or 32 bits.
          5. Set "LDAC Playback Quality" to Optimized for Audio Quality (990kbps).

          iOS users

          Apple devices do not support high-resolution Bluetooth codecs like LDAC. To experience true lossless audio on an iPhone or iPad, you must use a wired USB DAC (Digital-to-Analog Converter).

          When the "Pure" Audio Processing setting is enabled, Wesper completely bypasses the browser's audio processing pipeline, delivering the untouched FLAC bitstream directly to your device's audio HAL.
